# SecureCloud DevSecOps

End-to-end enterprise DevSecOps project demonstrating:

- Secure software development
- CI/CD automation
- Docker containerization
- AWS cloud infrastructure
- Terraform Infrastructure as Code
- Kubernetes deployment
- Application security
- Container security
- Infrastructure security
- Monitoring and logging
- Runtime security
- Incident response

## Project Architecture

Developer → GitHub → CI/CD → Security Scans → Docker → ECR → Kubernetes/EKS → Monitoring → Security Response
